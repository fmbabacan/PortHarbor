# Support

## Choose the right channel

- Reproducible bug: open a bug report with sanitized diagnostics.
- Focused feature proposal: open a feature request describing the user problem.
- Security vulnerability: use GitHub private vulnerability reporting.

## Before requesting help

Confirm that you are running the latest release on macOS 15 or later. Include the PortHarbor version, macOS version, processor architecture, expected result, observed result, and clear reproduction steps.

PortHarbor is maintained as an open-source project. Support is provided on a best-effort basis, with priority given to security, privacy, incorrect process targeting, crashes, and reproducible regressions.

Never publish passwords, signing keys, environment values, private repository paths, or sensitive process arguments in an issue.
