# PortHarbor Demo

The PortHarbor v1 demo is designed to show the complete local workflow without accounts, configuration, or elevated permissions.

1. Launch PortHarbor from Applications.
2. Observe the automatically discovered IPv4 and IPv6 TCP listeners.
3. Select a service to inspect its process, ancestry, project evidence, confidence, exposure, and health.
4. Open the menu bar view and confirm that it reflects the same service snapshot as the main window.
5. Open the timeline to review privacy-preserving changes retained for 24 hours.
6. Select an eligible development service and review the Safe Stop explanation and SIGTERM confirmation.
7. If the service remains alive, show that SIGKILL requires a second, separate confirmation and fresh identity validation.

A recorded visual demo and repository screenshot must be captured from the installed build after Screen Recording permission is granted to the terminal or host application performing the capture. This permission is needed only to produce repository media; PortHarbor itself does not require Screen Recording permission.
